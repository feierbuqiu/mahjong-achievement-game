## What the production run establishes

The generic Lean implication is kernel-proved. Natively compiled component
checks processed every recorded row: 778,532,864,302 SAFE symmetry orbits,
35 layers, 3,686 nonempty buckets and 17,317 frames. The recorded empty label
is P. This supports a second-player win under the declared specification,
execution, input-custody and bookkeeping assumptions.

It is not a typed whole-input execution of all theorem hypotheses over one
in-memory input, a closed actual-input Lean declaration, or a second independent
execution. Cross-layer identity relies on fixed paths, recorded Windows
deny-write/delete custody and equal before/after maps. These records support
the custody account; they do not verify the operating system or hash each
individual read independently.

The new offline close-event check does not retroactively add a gate to
historical production. The deleted-final-row control observed a false native
Boolean that production did not gate. The changed-target control used distinct
roots, unlike production. Neither control establishes the stronger production
detection claim formerly attributed to it.
